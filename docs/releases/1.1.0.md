# Lilt Notes 1.1.0

Floating notes for macOS, with Apple Spotlight integration and compatibility fixes verified on macOS 27 Golden Gate.

## What's changed

- **Apple Spotlight:** search current notes from the app's Tab view, with last-edit dates supplied for recency ranking. Open a result directly in Lilt. Spotlight controls the final order and may also consider relevance or usage.
- **Reliable Quit:** fixed a possible shutdown hang when an asynchronous Quit request waits for the final save. The latest editor contents are saved before the app exits.
- **Writing Tools on macOS 27:** updated on-device model generation and error handling, while retaining the macOS 26 implementation.
- **Window appearance:** validate native material support at runtime and keep command panels readable when standard rendering is needed.
- **Documentation:** added Spotlight guidance, Golden Gate compatibility details, and a repeatable native compatibility check. The README includes light and dark screenshots.

## Download and update

Download **Lilt-Notes-1.1.0-macOS-arm64.zip**, quit Lilt, unzip the download, and replace **Lilt Notes.app** in Applications. Open it once to refresh the local Spotlight index. Your notes, pins, and preferences remain in their existing locations.

The app requires an Apple silicon Mac and macOS 14 or newer. Spotlight's app-scoped Tab view requires macOS 26 or newer. On-device writing assistance requires macOS 26 or newer, an eligible Mac, Apple Intelligence enabled, and the local model downloaded.

The app is ad-hoc signed and not notarized. See the [installation guide](https://github.com/shivams1208/lilt-notes#install) for first-open steps. The complete tracked source is included in **Lilt-Notes-1.1.0-Source.zip**, and **SHA256SUMS.txt** contains both archive hashes.

## Verification

Verified on **macOS 27.0 (26A428), Apple silicon**:

- 85 JavaScript tests passed, plus native storage, folder-sync, shortcut-routing, Writing Tools, and Spotlight tests.
- 24 window/menu combinations passed sizing and scrolling checks.
- Light, dark, and system appearances passed with native materials and the standard rendering fallback.
- Final edits persisted before asynchronous Quit, and simulated editor-process recovery preserved saved content.
- Live on-device grammar, translation, summary, and cancellation checks passed.
- Writing Tools source also compiled against the macOS 26.5 SDK.

These checks do not cover every macOS build or hardware configuration. Editor recovery was tested through a simulated termination notification; physical system-wide shortcut delivery and cross-device iCloud delivery were not part of this compatibility run. iCloud delivery and Spotlight ranking remain controlled by macOS.
